현재 원칙

SNS 비밀번호나 API 키는 브라우저에 저장하지 않습니다. 자동 게시 기능은 서버에서 계정 인증과 권한을 처리하도록 확장합니다.
오늘은 “한 영상을 여러 채널에 보내는 공통 구조”를 직접 만져보고, 그 다음 플랫폼별 컨셉이 왜 필요한지 추가하는 수업용 배포 버전입니다.
