    왜 필요한가요?

    이 단계에서 할 일

      완료 기준

      처음 연결할 때 한 번만

      Instagram 계정 연결 방법

      Meta App ID

      Meta for Developers의 DECHIVE MultiPost Business 앱에서 App ID 숫자를 확인해 입력하세요. App Secret은 입력하지 않습니다.

      1. Instagram 계정 종류 확인

        Business 또는 Creator인 Professional 계정이어야 합니다. Meta Verified 파란 배지는 필요하지 않습니다.

      2. Facebook Page 연결 확인

        이번 수업에서는 Facebook Login 방식의 Instagram API를 사용합니다. Instagram Professional 계정이 관리 중인 Facebook Page에 연결돼 있어야 합니다.

      3. Meta 앱 권한

        pages_show_list, pages_read_engagement, instagram_basic, instagram_content_publish 권한을 사용합니다.

      4. Meta 앱 도메인

        앱의 App Domains / JavaScript SDK 허용 도메인에 studio.dechive.dev를 등록합니다.

      5. 이 화면에서 연결

        Instagram 계정 연결 버튼 → Meta 로그인 → 권한 허용 순서로 진행합니다.

      6. 연결 완료 확인

        프로그램 화면에 Facebook Page 이름과 @Instagram계정이 표시되면 연결 완료입니다.

      7. 영상 게시

        영상은 Supabase Storage에 업로드한 뒤 공개 URL을 Instagram에 전달해 Reel을 게시합니다.

      App Secret은 이 사이트에 입력하지 않습니다. 오늘 수업은 본인 계정 테스트용으로 Meta JavaScript SDK의 사용자 토큰을 브라우저에만 보관합니다.
