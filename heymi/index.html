      Instagram 계정 연결 방법

      1. Instagram 계정 종류 확인

        개인 계정이 아니라 Professional 계정이어야 합니다. Instagram 설정에서 Business 또는 Creator로 전환합니다.

      2. Meta for Developers에서 앱 생성

        Meta 개발자 사이트에서 앱을 만들고 Instagram API 사용 사례를 추가합니다.

      3. Instagram API with Instagram Login 선택

        Facebook Page를 반드시 연결하는 예전 방식이 아니라 Instagram 계정으로 직접 로그인하는 방식을 사용합니다.

      4. 권한 설정

        instagram_business_basic과 instagram_business_content_publish 권한을 사용합니다.

      5. Redirect URI 등록

        Meta 앱의 Valid OAuth Redirect URI에 실제 프로그램 주소의 /api/instagram/callback을 정확히 등록합니다. 주소가 한 글자라도 다르면 연결되지 않습니다.

      6. 서버 환경변수 입력

        INSTAGRAM_APP_ID, INSTAGRAM_APP_SECRET, INSTAGRAM_REDIRECT_URI, SESSION_SECRET을 서버 환경변수에 넣습니다.

      7. 영상 저장소 연결

        Supabase Storage에 instagram-videos 버킷을 만들고 URL과 키를 서버에 설정합니다.

      8. 이 화면에서 Instagram 계정 연결

        Instagram 로그인 → 권한 허용 → 프로그램으로 돌아오면 계정 연결이 완료됩니다.

      9. 영상·설명·해시태그 입력 후 게시

        프로그램이 영상을 Storage에 올리고, Instagram이 영상을 처리한 뒤 실제 Reel을 게시합니다.

      App Secret과 Supabase Service Role Key는 브라우저 코드에 넣지 않습니다. 서버 환경변수에만 저장해야 합니다.
