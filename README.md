# DECHIVE STUDIO

`studio.dechive.dev`의 소스 저장소입니다.

## 역할

DECHIVE STUDIO는 콘텐츠를 매일 발행하는 블로그가 아닙니다.

**DECHIVE의 public HQ — 퍼스널 브랜드와 실제 작업을 한곳에서 이해할 수 있게 만드는 중앙 허브**입니다.

- `dechive.dev` → 지식과 검증의 원본
- `studio.dechive.dev` → 사람, 철학, 프로젝트, 책, 교육, 이력서
- GitHub → 실제 코드와 구현 증거
- YouTube / Naver / Threads / Instagram → 발견과 배포
- Discord → 관계
- Notion → 내부 운영

## Brand

**LEARN → VERIFY → BUILD**

- Learn: 먼저 배운다.
- Verify: 그대로 믿지 않는다.
- Build: 확인한 뒤 만든다.

Core belief:

> AI creates answers. Humans verify them.

Automation principle:

> Start with friction, not AI.

## Public routes

- `/` — 브랜드 스토리와 전체 허브
- `/about/` — 사람과 배경
- `/work/` — 대표 프로젝트
- `/work/association-system/` — 생활체육 협회 행정 시스템 Case Study
- `/book/` — 《만들기 전에 검증하라》
- `/education/` — AI 교육과 자동화 접근 방식
- `/resume/` — 웹 이력서
- `/card/` — 명함 QR 랜딩

## 원칙

1. AI를 넣기 위해 문제를 찾지 않는다.
2. 실제 불편에서 시작한다.
3. 검증되지 않은 결과를 완성된 것처럼 말하지 않는다.
4. 프로젝트는 기술 스택보다 문제와 검증 과정을 먼저 설명한다.
5. 콘텐츠는 `dechive.dev`, 전환과 협업은 Studio에서 맡는다.
