# DECHIVE — 생각의 재설계

The Architecture of Thought. 정답보다 그 답에 이르는 구조를 탐구하는 브랜드 아카이브.

## 배포 및 화면

- GitHub Pages: `main` 브랜치, 저장소 루트
- 실제 도메인: https://studio.dechive.dev (`CNAME` 유지)
- 메인: 선언 → 관점 → 실시간 판단 전환 → 글 아카이브 → 확인할 수 있는 기록 → 다음 기록
- 글 아카이브: `/notes/`
- 실물 기록: `/work/`
- 원칙: `/about/`
- 모바일: 별도 레이아웃(PC 축소 아님)
- 접근성: 메뉴 키보드 동작, reduce-motion, 정상 링크, no-JS 기본 콘텐츠
- 히어로 모션: SVG + CSS, scroll-lock 없음, 원격 이미지 없음

## 사실과 검증 기준

프로젝트의 효과 수치, 운영자 이력, 유료 프로그램 모집 여부를 임의로 주장하지 않습니다.
외부 채널로 이어지는 링크는 현재 공개된 출처를 사용합니다.
글 2편은 기존 `/notes/` 텍스트를 보존한 편집본입니다.

디자인 변경: `assets/site.css`
행동: `assets/site.js`
메인: `index.html`

과거 `/essays/` 주소는 기존 리다이렉트를 유지합니다. `CNAME`, 피드 `feed.xml` 유지.
