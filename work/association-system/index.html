CASE STUDY · PROCESS AUTOMATION

엑셀을 없애려고 만든 게 아닙니다.
엑셀이 사람 사이를 오가는 과정을 없애기 위해 만들었습니다.

상·하반기마다 반복되는 회원등록과 이적 업무. 각각의 파일은 작았지만, 여러 동호회에서 파일을 받고 다시 취합하는 중간과정이 임원진의 시간을 계속 가져가고 있었습니다.

01 · PROBLEM

문제는 엑셀이 아니었습니다.

회원등록은 매년 상반기와 하반기에 반복됩니다. 각 동호회는 밴드에서 Excel 양식을 내려받아 회원명부를 작성하고, 협회 임원진에게 전달합니다. 임원진은 여러 동호회에서 온 파일을 다시 모아 도 단위 협회에 제출할 수 있도록 정리합니다.

한 번만 보면 복잡해 보이지 않습니다. 하지만 이 일을 담당하는 임원진은 회원등록만 하는 전담 인력이 아닙니다. 파일을 기다리고, 누락을 확인하고, 최신본을 찾고, 다시 합치는 과정이 반복될수록 작은 일이 큰 관리 비용이 됩니다.

02 · TRANSFER

이적은 더 많은 사람과 문서를 거쳤습니다.

한 동호회에서 다른 동호회로 이동하려면 신청서를 만들고 필요한 직인을 받아 협회에 전달해야 합니다. 기존 방식에서는 HWP 문서를 만들고, 승인 주체를 찾아 서명을 받고, 다시 협회 임원진에게 전달하는 과정이 필요했습니다.

사람이 해야 할 판단은 남기되, 사람이 파일을 전달하는 일까지 해야 할 이유는 없었습니다.

03 · REDESIGN

BEFORE
  1. 양식 다운로드
  2. 동호회별 작성
  3. 임원진에게 전달
  4. 여러 파일 취합
  5. 누락·최신본 확인
  6. 제출 양식 재정리
AFTER
  1. 사이트에서 직접 등록
  2. 데이터 즉시 저장
  3. 승인 대상에게 알림
  4. 협회에서 전체 조회
  5. 상태를 한곳에서 확인
  6. 필요할 때 Excel/HWP 생성

04 · PRINCIPLE

최종 제출 방식은 억지로 바꾸지 않았습니다.

상위 기관이 Excel 또는 HWP를 요구한다면 그 형식은 유지합니다. 대신 그 문서를 만들기 전까지 내부에서 반복되던 전달, 취합, 재입력 과정을 줄입니다. 디지털 전환은 모든 것을 새 방식으로 바꾸는 것이 아니라, 바꿀 수 있는 부분에서 실제 불편을 줄이는 일이라고 생각합니다.

05 · IMPLEMENTATION

Member Registration

회원등록 기간, 신청 상태, 승인·반려, 전체 명부 관리.

Transfer Approval

이적 신청과 필요한 승인 단계를 시스템 안에서 추적.

Document Export

협회가 필요한 시점에 Excel/HWP 문서를 생성.

External Information

외부 대회 공지와 첨부 문서를 수집해 반복 확인을 줄임.
